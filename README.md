## 安裝

1. 用 Android 手機開啟本頁，點選上方「下載 Android APK」。
2. 下載完成後開啟 CDG.apk，依系統提示允許該瀏覽器或檔案管理員安裝未知應用程式。
3. 保留 Google Play 安全防護，完成系統要求的安全檢查後安裝。若遭封鎖，請回報提示，不要關閉安全防護。
4. 啟動「雞鴨鵝」，連線並登入或註冊帳號。

從版本頁下載時，請選 Assets 中的 **CDG.apk**；Source code 是本下載說明的原始檔，無法安裝遊戲。
