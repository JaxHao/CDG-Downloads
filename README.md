本版更新第一部主線、九章敵人主題、金幣抽獎與獎券商店、家園背景、問題回報及診斷；最低可遊玩版本為 0.1.11。

本次為刪檔 Beta，以玩法驗證與玩家反饋為主。測試資料日後會清除，本次更新沒有重設帳號；會員正式付款尚未開放。行動裝置的背景恢復與跨裝置特效問題仍待實機確認。

Android 支援 ARM64／x86_64，Android 7.0 以上，約 222 MB。套件名稱 org.cdg.game，沿用正式簽章，可覆蓋安裝。

Windows 支援 x64，壓縮包約 206 MB。請完整解壓縮後，從最外層 CDG.exe 啟動；程式位於 Runtime，登入、設定與日誌保存在同層 Data。更新時保留 Data 資料夾，其他檔案一併替換。

macOS 目前提供 **啟動診斷 r2**，約 229 MB，macOS 13 以上，Intel／Apple Silicon 通用。完整解壓縮後，從資料夾內「雞鴨鵝.app」啟動；Data 會自動建立，更新保留 Data。若啟動失敗，請按「複製診斷」回報錯誤代碼、實際路徑與系統原因，不必手動建立 Data 或查程序名稱。先前失敗的根因仍待實機報告，**尚未經 Mac 實機驗收**；臨時簽章、未經 Apple 公證，首次可能需在系統「隱私權與安全性」允許開啟。
